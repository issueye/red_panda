## 1. Goal

在本地三层架构下交付可用的 **定时触发 Agent run** 能力：

- Gateway 持久化任务定义并内置调度循环
- 到期自动走既有 run 管线（可审计、可恢复）
- Desktop 可管理任务与查看历史
- 默认无人值守安全策略
- 可选 Agent `schedule.*` 工具

**一句话交付：** 用户配置「何时 + 什么 prompt + 哪个工作区」，Gateway 到点自动跑，结果落在 session/Activity。

---

## 2. Non-Goals（本版本边界）

| 不做 | 说明 |
| --- | --- |
| OS 级计划任务注册 | 不写 Windows Task Scheduler / launchd |
| 分布式调度 | 单 Gateway 进程 |
| 完整 RRULE | 仅 one_shot / interval / cron5 |
| 邮件/短信通知 | 仅 App 内事件与历史 |
| 替换 Todo/Goal | 独立领域 |
| MCP 任务市场 | 不兼容外部 tasks MCP |
| catch-up 全量补跑 | 默认最多补一次 + 限流 |

## 8. Risk register

| Risk | Impact | Mitigation |
| --- | --- | --- |
| 无人值守高风险工具 | 数据损坏/误操作 | 默认 deny + allowlist；UI 强提示 |
| 调度与 run 双写不一致 | 历史 status 错 | 终态 hook + 对账字段 last_status |
| 测试 flaky（真时钟） | CI 不稳 | Clock 注入；loop 可 disable |
| per_run_process 并发打满 | 资源抖 | MAX_INFLIGHT + overlap skip |
| 与 Goal 并发抢 session | 业务错乱 | 默认 new_each_run；fixed_session 文档警告 |
| cron 库时区踩坑 | 错峰触发 | 单测固定 TZ；文档示例用 Asia/Shanghai |
