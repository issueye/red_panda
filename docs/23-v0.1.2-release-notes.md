# red_panda v0.1.2 Release Notes

Date: 2026-07-10

Status: implemented.

v0.1.2 delivers the MCP-1 configuration backend slice. It defines and persists MCP server configuration without starting MCP processes.

## Delivered

- MCP server config and timeout protocol DTOs with deterministic defaults.
- Gateway MCP server config persistence and migration.
- Gateway MCP server config CRUD APIs under `/api/v1/mcp/servers`.
- Validation for names, commands, env keys, positive timeouts, tool allowlists, and risk overrides without command execution.
- Sensitive environment-value redaction in API responses and preservation during partial updates.
- Repository, service, controller, protocol, and external compatibility coverage for MCP config CRUD.

## Not Included

- MCP stdio process startup.
- MCP initialize/tools-list/tools-call.
- Runtime MCP tool registry or execution.
- Desktop MCP settings UI in the v0.1.2 backend scope. The UI is implemented separately by the v0.1.4 configuration slice.
- HTTP MCP transport.

## Verification

The v0.1.2 implementation includes these verification surfaces:

- Go protocol and Gateway tests for MCP config DTOs, persistence, validation, redaction, and CRUD.
- Protocol compatibility checks for the public MCP config API.
- Existing non-MCP tests remain part of the combined release gate.
