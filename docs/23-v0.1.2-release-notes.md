# red_panda v0.1.2 Release Notes

Date: 2026-07-09

v0.1.2 is planned as the MCP-1 implementation slice.

## Planned

- MCP server config protocol DTOs.
- Gateway MCP server config persistence.
- Gateway MCP server config CRUD APIs.
- Validation for MCP server names, commands, timeouts, tool allowlists, and risk overrides.
- Protocol compatibility coverage for MCP config CRUD.

## Not Included

- MCP stdio process startup.
- MCP initialize/tools-list/tools-call.
- Runtime MCP tool registry or execution.
- Desktop MCP settings UI.
- HTTP MCP transport.

## Verification

Before release, v0.1.2 must pass:

- Go protocol/gateway tests for MCP config DTOs and CRUD.
- Protocol compatibility checks for the public MCP config API.
- Existing frontend gates if Desktop files change.
- Full release gate before tagging.
