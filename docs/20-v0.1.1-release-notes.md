# red_panda v0.1.1 Release Notes

Date: 2026-07-09

v0.1.1 is a design and stabilization release. It keeps the v0.1.0 baseline stable while documenting the next MCP stdio tools direction and tightening release planning.

## Included

- MCP stdio tools design for future implementation work.
- v0.1.1 execution planning and stabilization scope.
- Release hygiene docs for verification, boundaries, and follow-up release work.
- Fake MCP server test matrix and anti-pattern guidance.

## Not Included

- MCP implementation.
- HTTP MCP support.
- Plugin marketplace.
- Remote access.
- Major UI redesigns.

## Verification

This release uses a docs-only gate because the v0.1.1 scope is documentation and planning only.

If later v0.1.1 changes include code, they must pass the relevant gates before release:

- Go backend gate.
- Frontend gate.
- Protocol compatibility gate.

## Next

v0.1.2 and later releases should begin MCP implementation slices based on the stdio tools design, with each slice scoped, verified, and released independently.
