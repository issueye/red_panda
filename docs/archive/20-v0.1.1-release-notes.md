# red_panda v0.1.1 Release Notes

Date: 2026-07-09

v0.1.1 is a design and stabilization release. It keeps the v0.1.0 baseline stable, normalizes the Desktop UI component layer, and documents the next MCP stdio tools direction.

## Included

- MCP stdio tools design for future implementation work.
- v0.1.1 execution planning and stabilization scope.
- Release hygiene docs for verification, boundaries, and follow-up release work.
- Fake MCP server test matrix and anti-pattern guidance.
- Desktop UI normalization with shared primitives for badges, panel headers, tabs, fields, empty/error states, and custom dropdowns.
- Removal of native Desktop `<select>` controls in favor of the shared `SelectMenu`.
- Browser coverage updated for custom dropdown interactions.

## Not Included

- MCP implementation.
- HTTP MCP support.
- Plugin marketplace.
- Remote access.
- Major UI redesigns.
- MCP settings UI.

## Verification

This release uses the frontend gate plus the existing release hygiene checks because v0.1.1 includes Desktop UI code.

- `npm test`
- `npm run test:ui`
- `npm run build`
- Full release gate before tagging.

## Next

v0.1.2 and later releases should begin MCP implementation slices based on the stdio tools design, with each slice scoped, verified, and released independently.
