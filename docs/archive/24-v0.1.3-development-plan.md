# v0.1.3 Development Plan

Updated: 2026-07-09

v0.1.3 is a Desktop clarity and localization stabilization slice after the v0.1.2 planning baseline.

This slice keeps backend contracts unchanged. It focuses on making the existing Desktop easier to scan, more consistently Chinese, and less dependent on brittle UI automation assumptions.

## 1. Goal

v0.1.3 should deliver:

1. A simpler Desktop information hierarchy with fewer subtitles and explanatory helper lines.
2. Chinese labels for user-facing status, risk, event kind, memory, and runtime values.
3. Custom dropdown coverage without native Desktop `<select>` controls.
4. Stable Playwright assertions for event timelines where the Gateway projection can legitimately emit 4-6 events.
5. Documentation that records the UI normalization and simplicity rules.

## 2. Non-Goals

Do not include these in v0.1.3:

- MCP Runtime process execution.
- MCP `tools/list` or `tools/call`.
- Desktop MCP settings UI.
- Provider or tool behavior changes.
- Broad visual redesign beyond clarity, spacing, and component normalization.

## 3. Deliverables

| Order | Deliverable | Scope | Done when |
| --- | --- | --- | --- |
| 1 | Desktop label normalization | `modules/desktop/frontend/src` | Shared display helpers translate visible statuses, risk levels, memory labels, event kinds, and runtime modes. |
| 2 | Simpler panel hierarchy | Desktop components | Main panels rely on concise titles and remove non-essential subtitles/helper text. |
| 3 | Custom dropdown verification | Desktop UI/tests | No native `<select>` remains in Desktop frontend source or HTML entries. |
| 4 | Test stability | Playwright tests | Timeline assertions verify behavior without depending on one exact volatile event count. |
| 5 | Documentation sync | `docs/*`, `README.md` | v0.1.3 plan is linked and status docs reflect the clarity slice. |

## 4. Verification

Focused gate:

```powershell
cd modules\desktop\frontend
npm test
npm run test:ui
npm run build
cd ..\..\
rg "<select|</select" modules\desktop\frontend\src modules\desktop\frontend -g "*.html"
```

If backend files are not touched, Go tests are not required for this slice.

## 5. Exit Criteria

v0.1.3 is done when:

1. Desktop visible labels are consistently Chinese except protocol names, tool names, backend errors, and file/API identifiers.
2. Main panels no longer use explanatory subtitles by default.
3. Existing Desktop workflows still pass Playwright coverage.
4. Native Desktop `<select>` controls are absent.
5. The implementation is committed and pushed.
